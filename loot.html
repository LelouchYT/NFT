How To Use Loot Logger Viewer

CSV Format (AO Loot Logger Export)

Supports the full AO Loot Logger semicolon-delimited export format with these columns:

timestamp_utc ; looted_by__alliance ; looted_by__guild ; looted_by__name ; item_id ; item_name ; quantity ; looted_from__alliance ; looted_from__guild ; looted_from__name ; died ; died_player_guild ; killed_by ; killed_by_guild ; average_est_market_value ; cluster

The died column is used to auto-detect ganks — if the looter dies (appears in the died column) the item is flagged as Ganked / Lost.

Gank Detection

When the log's died field matches the player who looted the item, that item is marked as Ganked — meaning the player looted it but was then killed and lost it. These entries can be manually deleted from the split via Edit Mode.

Edit Mode (Log Editing)

Click Edit Log in the toolbar to enter Edit Mode. In this mode, clicking any item card will remove it from the loot split calculation. Use this to clean up items that were not part of the official split (e.g. personal loot, items looted from guildmates).

Market Values

The average_est_market_value column is used to calculate estimated silver value per item. The Guild Value Summary card shows total, ganked, secured, and deleted values. These are estimates from the data at time of export and may not reflect live market prices.

Guild Filter

The guild filter (default: NoFreeThinkers) restricts player cards to only members of the specified guild. Toggle it off to see all guilds that looted during the CTA.

Discord Split Export

The Discord export includes a formatted table with silver values per player. Ganked and deleted items are excluded from the split totals automatically.
